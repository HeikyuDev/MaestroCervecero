Retiro de barriles

Una vez por día, el sistema envía a cada cliente con barriles con la devolución vencida un correo con el enlace para proponer la fecha y hora del retiro.

Desde esta hora se envía el recordatorio del día. Se repite cada día hasta que el cliente coordina el retiro.

Hasta cuántos días hacia adelante puede proponer el cliente el retiro; también es la vigencia del enlace. Un número entero entre 1 y 30.
