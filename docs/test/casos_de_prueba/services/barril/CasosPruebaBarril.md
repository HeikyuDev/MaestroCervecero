### 3. `altaBarril(BarrilFormDTO barrilFormDTO)`

Se valida en este orden: capacidad, usos máximos antes de mantenimiento, existencia del fabricante y, recién con el fabricante confirmado, el número de serie duplicado para ese fabricante; con todo validado, genera el identificador interno (BRL-NN) con la secuencia y guarda. En todos los casos de falla, el resto de los datos del DTO son válidos.

|**CP-AB-03**|Capacidad igual a cero _(Límite)_|`capacidad: 0.0`|`capacidad <= 0` $\rightarrow$ **TRUE**|Lanza `ReglaNegocioException` ("La capacidad debe ser mayor a 0"). No consulta la BD.|
|**CP-AB-04**|Fabricante de barril inexistente|`capacidad: 50.0`, `idFabricanteBarril: 99L` (No existe o dado de baja)|`fabricanteBarrilRepository.findById(99L)` $\rightarrow$ **Optional.empty()**|Lanza `RecursoNoEncontradoException` con mensaje "No se encontró el fabricante de barril con ID: 99". |**CP-AB-05**|Número de serie duplicado para el mismo fabricante|`numeroSerie: "BAR-01"`, `idFabricanteBarril: 1L` (Ya existe un barril activo con ese número de serie para ese fabricante)|`existsByNumeroSerieIgnoreCaseAndFabricanteId("BAR-01", 1L)` $\rightarrow$ **TRUE**|Lanza `RecursoDuplicadoException` con campo `numeroSerie` y mensaje "Ya existe un barril con el número de serie 'BAR-01' para el fabricante seleccionado". |**CP-AB-06**|Mismo número de serie permitido para un fabricante distinto|`numeroSerie: "BAR-01"`, `idFabricanteBarril: 2L` (El número de serie existe, pero para el fabricante `1L`, no para el `2L`)|`existsByNumeroSerieIgnoreCaseAndFabricanteId("BAR-01", 2L)` $\rightarrow$ **FALSE**|Persiste el barril asociado al fabricante `2L` y retorna el DTO con el número de serie `BAR-01`.|

|**CP-AB-09**|Usos máximos antes de mantenimiento igual a cero _(Límite)_|`usosMaximosAntesMantenimiento: 0`|`usosMaximosAntesMantenimiento <= 0` $\rightarrow$ **TRUE**|Lanza `ReglaNegocioException` ("Los usos máximos antes de mantenimiento deben ser mayores a 0"). No consulta la BD.|
|**CP-AB-10**|Normalización del número de serie antes de validar y guardar|`numeroSerie: "  bar   01 "` (resto válido)|El Service normaliza el número de serie antes de validar, consultar la unicidad y guardar (sin cambiar las mayúsculas)|Consulta la unicidad con `"bar 01"`, persiste la entidad con ese valor (`save` y `flush`) y no modifica el `FormDTO`.|
|**CP-AB-11**|El número de serie vacío tras normalizar|`numeroSerie: "   "` (solo espacios)|El número de serie normalizado queda vacío|Lanza `ReglaNegocioException` ("El número de serie es obligatorio"). No consulta el repositorio.|

### 4. `modificarBarril(Long id, BarrilFormDTO barrilFormDTO)`

Localiza el barril primero, bloqueándolo (`buscarPorIdParaCambiarEstadoOperativo`, solo activos) mientras se valida y se escribe; recién si existe se valida la capacidad (mayor a 0 y no menor al contenido actual del barril), los usos máximos antes de mantenimiento, la existencia del fabricante (que puede reasignarse) y la duplicidad del número de serie para ese fabricante, excluyendo al propio barril. El identificador interno no se modifica.

### 5. `bajaBarril(Long id)`

Localiza el barril bloqueándolo (`buscarPorIdParaCambiarEstadoOperativo`, solo activos) para que un envasado o despacho simultáneo no cambie su estado operativo entre la validación y la baja.

|---|---|---|---|---|
